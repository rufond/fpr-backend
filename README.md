# FPR Backend

Backend сайта [fpr.rufond.su](https://fpr.rufond.su/) — неофициального проекта о ЗПИФ «Фонд первичных размещений».

Сервис собирает данные о фонде из открытых источников и предоставляет их сайту, позволяя держателям паёв следить за составом фонда, стоимостью пая и изменениями активов.

## Запуск

Требования:

- Go 1.26+
- PostgreSQL

Создайте файл с переменными окружения на основе примера:

```bash
cp .env.example .env
```

Укажите параметры подключения к PostgreSQL, а также `FPR_ADMIN_LOGIN` и bcrypt-хеш пароля в `FPR_ADMIN_PASSWORD_HASH`, затем загрузите переменные и запустите приложение:

```bash
set -a
source .env
set +a

go run ./cmd/fpr
```

При запуске приложение автоматически применит миграции базы данных.

Для запуска тестов:

```bash
go test ./...
```
